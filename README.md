# Snoopyboard

Snoopyboard is a 4 key macro pad with a rotary encoder as well as an OLED Display, uses QMK firmware

## Features:

- 4 Mechanical keys arranged in an arrow key formation
- EC11 Rotary Encoder, controlling volume on rotation an muting when pressed
- 128x32 OLED display (still needs to be programmed whoops!)
- Seeed XIAO RP2040
- Custom PCB

## Case

The base connects to the top with 4 M3x16mm Screws, printed in 3 pieces total. (modeled in Fusion360)

## Firmware

Snoopyboard uses QMK firmware for everything. 

- the rotary encoder changes volume. press to mute
- The 4 keys currently pause/play music, skip or go to previous song and presses right ctrl (my keybind for muting on discord)
- The OLED will be snoopy but that is currently not finished
